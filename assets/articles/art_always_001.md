# What Is Always True

## The Search

We look for truth in changing things. Insights come and go. States come and go.

Is there something always true?

## The Discovery

Awareness is always present. Before any thought, during any thought, after any thought.

This is always true.

## The Test

Throughout this day, check: Is awareness present?

The answer is always yes. Because you couldn't check without it.

## The Implication

If awareness is always present:
- You don't need to create it
- You can't lose it
- It's the most reliable thing there is

## The Trust

You can trust awareness. It's never not here.

Everything else changes. This doesn't.

## The Rest

Knowing what is always true, you can rest.

Not rest from activity. Rest IN activity.

The constant ground beneath all change.

## The Living

Living from what is always true is living from stability.

Circumstances change. Emotions change. You - as awareness - don't.

## The Question

What is always true for you? Right now?

The answer is what you are.
